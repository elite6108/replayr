- snip/session.rs: `SessionBroker { next: AtomicU64, pending: Mutex<HashMap<u64, SyncSender<Option<CloudSession>>>> }`.
  Unknown requestIds are ignored; timeout → None.
- snip/cloud.rs: static warm client (5 s connect, 60 s total). `warm(api_base)` pings when the snip
  opens so TLS is ready by mouse-up. `upload(api_base, token, png) -> Result<CloudOk, CloudError>`
  where CloudError = Unauthorized|TooLarge|Busy|RateLimited|Invalid|Network|Server, mapped from `code`.
- In snip/mod.rs `save()`: after the local save, if signed in and auto_upload → mark local row
  uploading → pull session → upload the in-memory PNG → on success copy the link (or the image if
  copy_mode == "image") → row ready with cloud_id/slug/share_url → if replacedOldest, mark matching
  local rows evicted → overlay LinkCopied / LinkCopiedReplacedOldest → emit `screenshot-updated`.
  Failure → keep local, copy image, overlay UploadFailedImageCopied, row failed + upload_error.
- Commands (+ app.toml): `screenshot_provide_session`, `screenshot_retry_upload`, `screenshot_sync_cloud`.
- tracing timings per stage. Target: link in clipboard <1.5 s for 1080p regions on a warm connection.
- Tests: CloudError mapping from JSON fixtures, apiBase allowlist, broker timeout, unknown requestId ignored.
